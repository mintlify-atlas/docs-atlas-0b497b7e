usbliter8-fun is a research jailbreak toolkit targeting the **iPhone 11 Pro (A13/T8030)** on **iOS 27.0 beta**. It leverages the `usbliter8` SecureROM exploit — delivered via a Raspberry Pi Pico 2 (RP2350) — to enter PWN DFU mode, then builds a heavily-patched custom firmware with kernel bypasses, hacktivation, and a full Sileo/bootstrap installation.

<Warning>
  Running this toolkit **will erase your device entirely** and break SEP, passcode, Wi-Fi, baseband, and all Apple services. Use only on a **spare iPhone 11 Pro**. This is for developers who enjoy breaking their devices.
</Warning>

## How It Works

The jailbreak chains several techniques together:

<Steps>
  <Step title="Enter PWN DFU">
    Place the device in DFU mode, then connect it to the Raspberry Pi Pico 2 running the `usbliter8` exploit payload. The Pico blinks twice during exploitation and stays lit on success — `PWND:[usbliter8]` confirms the device is exploitable.
  </Step>
  <Step title="Build & Restore Custom Firmware">
    Run `make_cfw.py` to patch iBSS, iBEC, the kernelcache, TXM, RestoreRamdisk, and DeviceTree. Start `tss_proxy_server.py` to sign the unsigned beta firmware, then run `restore_cfw.sh` to flash it.
  </Step>
  <Step title="Boot via SSH Ramdisk">
    Re-enter PWN DFU and boot the SSHRD chain to access the filesystem. Dump the SEP firmware and extract the APTicket needed for subsequent normal boots.
  </Step>
  <Step title="Normal Boot + Post-Install">
    Build the normal boot chain with `get_boot.py`, boot with `boot.py`, apply userland patches (hacktivation, ScreenTime fix), set up USB internet, and install the bootstrap with Sileo.
  </Step>
</Steps>

## Supported Devices

<Info>
  Currently only **iPhone 11 Pro (iPhone12,3)** targeting **iOS 27.0 beta 2 (24A5370h)** and **beta 3 (24A5380h)** is fully supported. Other A12/A13 devices require re-deriving offsets in IDA Pro.
</Info>
